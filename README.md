# dpp-platform
Tekstil ürünleri için Dijital Ürün Pasaportu (DPP) platformu.

## Dosyalar
- index.html → Login sayfası
- dashboard.html → Ürün listesi
- ekle.html → Yeni ürün ekleme formu
- dpp.html → Public DPP sayfası (QR ile açılır)
- style.css → Ortak stiller
- supabase.js → Veritabanı bağlantısı
